# Castledown visual assets

`night-valley.png` is original art generated with the built-in imagegen tool for this project.

Prompt: Portrait 2D fantasy game background: a moonlit medieval valley in deep navy and teal, thin clouds, stars and a crescent moon. Layer distant mountains, pine forests, a misty river and warm lanterns; confine castles to the lower side edges. Leave the middle open for the playable tower. Hand-painted strategy game atmosphere, no characters, central castle, text or UI.

The font files are bundled locally from [Google Fonts](https://github.com/google/fonts): Cinzel for titles and numbers, Barlow Condensed for interface labels. Both use the SIL Open Font License; the original license texts are retained in `public/licenses/` and shipped with the HTML5 build.
